# Object-Detection-Model
 A deep learning project that demonstrates object detection through simultaneous image classification and bounding-box localization using a custom Convolutional Neural Network (CNN) built with TensorFlow/Keras.

The project uses the MNIST dataset and transforms each handwritten digit into an object placed at a randomized position within a larger image canvas. The model learns both what the object is and where the object is located.

The project was completed as part of an Industrial Program on Machine Learning at Fox Trading.
